      Rail arrivals

      Times use simulated seconds since reset. Walking delays postpone requests. Select Rail arrivals in Passenger demand to use this plan.

      Rail departures

      Times use simulated seconds since reset. Requests span the inclusive window. A connection succeeds when alighting plus transfer time meets departure. Missed pod journeys continue. Select Rail arrivals and departures to use both plans.

      Coupling sites

      Select a straight guideway on the map, and set Compact as its only vehicle class in Selection. Then add a site on it, or use it for a site. Positions are meters from the start of the guideway.

      Coupling corridors

      Pods couple at the assembly site and separate at the split site. Select each guideway of the path on the map in order, from the assembly site to the split site, and add it.
